# 📝 To-Do API (FastAPI & PostgreSQL)

API REST complète pour la gestion de tâches, conteneurisée avec Docker Compose et connectée à une base de données PostgreSQL.

## 🛠️ Stack Technique
- **Framework** : FastAPI (Python 3.11)
- **ORM / BDD** : SQLAlchemy & PostgreSQL 15
- **Serveur ASGI** : Uvicorn
- **DevOps** : Docker & Docker Compose
